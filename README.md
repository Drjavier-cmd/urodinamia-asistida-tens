# Urodinamia asistida para TENS

Aplicación web independiente del curso **Urodinamia asistida**. Su código, progreso, evaluación, recursos y publicación están separados del programa de cuidados urológicos del paciente hospitalizado y de la plataforma `chatgpt.site`.

## Alcance

- Nueve módulos secuenciales.
- Pretest diagnóstico, actividades formativas y postest.
- Preguntas críticas independientes del porcentaje final.
- Escenarios técnicos y checklist práctico supervisado.
- Persistencia local del avance en el navegador.

Completar la ruta digital, aprobar conocimientos y demostrar competencia clínica institucional son resultados distintos. La aplicación no sustituye capacitación práctica, delegación, supervisión ni protocolo local.

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación

```bash
npm test
```
